- 신규 후보 미구현: 117. 전수 원문 조사·정의 확인·최종 분류는 미완료.
- 마스터 최종 기준에 따른 완전 구현 수는 재감사가 필요하며 15라고 주장하지 않습니다. 신규 두 엔진은 2D 한정, 외부 패키지 결과 비교 미완료입니다.
- SLINK, CLINK, NN-Chain은 linkage의 구현 기법으로 별도 검토해야 합니다. Bayesian GMM/DP-GMM, Bernoulli mixture/latent class analysis 등은 중복 여부와 모델 정의를 먼저 확인하세요.
- src/data/candidates.json이 신규 후보 목록의 코드 원본입니다. 상태 변경 시 이 문서도 갱신하세요.
