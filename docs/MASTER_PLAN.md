# 전체 마스터 개발 계획 — 53개 소스

기존13개와 신규119개 후보 전부가 범위다. 현재 소스53개=기존13+후보40, 미구현79개, 엄격한 완전 구현 인증0개다. 공개 안정50개와 새 순차3개의 개발 상태를 구분한다. 119개 목표를 이 개발 단위로 축소하지 않는다. 이전25/44/50개 원문은 sessions의 각 archive에 보존한다.

## 보존하고 확장한 기반

기존13 모듈·32프리셋·홈4개 Worker/11순환·디자인·편집/Undo/Redo/제스처/입출력·비교·가이드를 유지한다. 이름만 등록하거나 K-Means로 대체하지 않는다. SOM/LVQ/NG/GNG는 관련 학습법으로 구분한다. 등록 수·실행 가능 수·독립 방법 수·완전 인증 수를 혼동하지 않는다.

53개는 lazy registry/스키마·Worker 실제 취소·전체 원본과 표시 축 분리·byte 자원 검사·delta Trace/48checkpoint/역진·유형별 native 결과·실제 mini와 수학 콘텐츠를 함께 연결한 상태다. 알고리즘의 원문 가속·추론법·분포 가정·정확/근사·수치와 데이터 제약은 각 research에 명시한다. 일부 논문의 접근 제한과 원서 전체 미열람을 원문 조사 완료로 올리지 않는다.

## 이번 순차 개발 단위

BSAS는 배정 즉시 평균 갱신, MBSAS는 첫 pass seed 선택/둘째 pass 유보 배정, TTSAS는 두 경계/유보 재검사/무진전 다음 pass의 첫 pending 생성이다. 세 모듈과 전용 ND 분석·실제 가이드·native 결과·공식 Python/NumPy 검산을 연결했다. 실제 순서와 전체 차원을 유지하고 최대 q를 데이터 개수 상한으로 쓰지 않는다. [SEQUENTIAL](research/SEQUENTIAL.md)을 기준으로 최종 통합·배포를 마친다.

## 다음 순서와 전체 남은 범위

1. 현재53개 전체 회귀·cross·성능/문서·안정 커밋을 완료하고 검증된 소스만 main/Pages에 반영한다. 중간 실패·미완료를 그대로 기록한다.
2. NEXT_50_QUEUE의 PCK/PCM/FPCM/MPCK/Constrained Spectral·Leader 정의를 이어간다. PCK 원문 consistent closure와 finite penalty, FPCM1997/PFCM2005, ND warm-start, generalized eigen 문제를 구분한다. 검증된 hard 스키마를 무근거 soft semantics로 바꾸지 않는다.
3. 남은 중심/밀도/계층/그래프·부분공간·확률/혼합·실제 신경망/딥·행렬/시계열/스트림 후보를 모두 원문/정의→입출력→실제 계산→Trace→고유 분석/파라미터→교재/mini→독립 수치→브라우저의 세로 단위로 개발한다. 일부 후보를 조용히 제외하지 않는다.
4. Bayesian/DP 모형·LCA와 Bernoulli·MFA/MPPCA·SLINK/CLINK/NN-chain의 변형/별칭/최적화를 정확히 분류한다. 이름만 늘리지 않는다.
5. typed 비교/적절한 지표·3D/PCA/고차원·시각 그래프·행렬/시간축 편집·진짜 증분 스트림·청크 입출력·transferable·Worker pool/계산 pause·필요한 가속을 병목 측정과 회귀 동등성에 따라 개발한다.
6. 적합한100~100만 이상의 실제 전체 데이터·장시간 peak/누수/FPS·취소 지연·여러 브라우저/장치를 측정한다. 쉬운 데이터의 Node 시간이나 테스트 개수를 보편 성능 보장으로 표시하지 않는다.
