# ClusterLab 통합 확장 마스터 계획

기준: v0.6, 9ecf190. 요청일: 2026-10-31 (Asia/Seoul). 이 요청은 단일 버전 시범 구현이 아닌 지속적인 플랫폼 확장이다. 이 문서는 다음 세션에서도 유효하며 사용자에게 마스터 명세 재입력을 요구하지 않는다.

## 변경하지 않는 원칙

실제 수학적 계산 → 정확성 → 실제 내부 Trace → 대규모 데이터 → 기존 UX 보존 → 독립 검증 순으로 판단한다. 후보 이름만 등록하거나 K-Means 래퍼로 다른 알고리즘을 사칭하지 않는다. 표시 표본과 계산 표본을 분리하고 근사 결과는 명시적 동의 없이 실행하지 않는다. 실패를 성공/빈 결과로 바꾸지 않는다.

## 보존 범위

기존 13개 엔진, 상세 연산/되감기/탐색/속도 1~200, 파라미터, 32개 프리셋의 정확한 값, 점 편집/100개 Undo·Redo/우클릭 이동/드래그 추가, CSV·JSON, 4개 비교, 쉬운/심화 가이드, 홈 4개 실제 데모와 11개 순환, GMM 수정, 반응형/색상/폰트/홈 배치를 보존한다. 기존 검증 보고서를 삭제하거나 덮어쓰지 않는다.

## 진행 단계와 의존 관계

1. 기준 구조·회귀 감사. 기존 테스트 146개 확보. 기존 알고리즘별 원문/검증 범위는 별도 재감사한다.
2. 119개 후보 원논문·정의·수식·입출력·중복·분류 전수 조사. 목록은 ALGORITHM_REGISTRY.md. 조사 상태와 엔진 구현 상태는 별개다.
3. 공통 파라미터/레지스트리/동적 엔진 로딩·입력검증·작업 예산. 기존 동기 run API는 검증 호환용으로 보존한다.
4. 600개 제한을 전 경로에서 제거. 바이트 기반 자원 예측, Trace 예산, 편집 차분, 렌더링 LOD, 대량 입출력/전송 최적화.
5. 실행 작업 관리. Worker 취소/진행/오류/해제부터 완성하고 pause 가능한 엔진, 기기별 Worker 풀, timeout 정책으로 확장한다.
6. 2D 중심/퍼지/밀도 계열을 하나씩 엔진→실제 이벤트→전용 시각화→파라미터→수학 가이드→수치·브라우저 검증까지 연결한다. 우선순위: Spectral, FCM, Affinity Propagation, Density Peaks, Bisecting, CURE, X/G-Means, Neural/Growing Neural Gas.
7. 다중 입력 계약을 먼저 확정: 3D/N차원 수치, 범주/혼합, 그래프, 행렬, 시계열, 스트림, 제약. 본질 데이터와 투영 좌표는 분리한다. 2D 계산을 고차원 지원이라 표시하지 않는다.
8. 그래프 입력/노드·간선·가중/방향/중첩 모델, 명시적 kNN 변환. Louvain/Leiden 등 구현 후 그래프 시각화·지표 검증.
9. 고차원/부분공간·범주·제약. CLIQUE/PROCLUS/K-Modes 우선. 실제 차원 연산과 전용 편집·투영·축 표현.
10. 확률/혼합 모델: 분포별 추론·EM/변분/샘플링을 구분하고 적절한 분포·우도 시각화.
11. 실제 신경망/딥 모델 학습. 런타임 라이선스/용량/브라우저 폴백 검증. 사전 결과 재생이나 가짜 학습 금지.
12. 행렬 이중군집·시계열·스트림 엔진 및 실제 출력. 행/열 소속, 시간축, 순차 유입, drift를 모델에 포함.
13. 도감의 검색/계열/입력/자동 K/노이즈/계층/중첩/연산/구현/검증/관련 링크 필터와 상세 페이지. 스키마 기반 실험실/호환 비교/조건에 맞는 지표.
14. Trace delta/체크포인트/청크/역탐색/저장 예산, 실제 상태와 시각 보간 구분. reduced-motion, 60FPS 목표를 실측.
15. 표준 파일 스키마, 스트리밍 파서/전송 TypedArray/버퍼 재사용/공간인덱스 등을 병목 실측 후 선택. 새 전역 점 수 상한 금지.
16. 전 엔진 원논문/독립 구현 비교, 단위/통합/Trace/브라우저/누수/취소/장시간·성능 검증. 100/1k/10k/100k/1M과 적절한 규모별 한계 기록.
17. 안정 변경만 main 반영·GitHub Pages 배포, Actions와 공개 동작 별도 확인. 미완료 항목을 노출할 때 상태를 정확히 표시.

## 완료 기준

후보 119개 전수 조사와 최종 분류, 구현 가능한 독립 방법/주요 변형의 실제 엔진·전용 Trace·시각화·파라미터·가이드·독립 검증을 완료해야 전체 목표 달성을 선언할 수 있다. 문서와 도감 등록 수를 완전 구현 수로 세지 않는다. v0.6 기존 엔진도 전체 마스터 기준 완료 여부를 재감사한다.

## 검증과 세션 종료 계약

안정 단위별 타입검사·lint·수치/회귀 테스트·프로덕션 빌드·Playwright를 실행한다. 브라우저 1920/1440/1024/800/768/390/320px, 가능할 때 Firefox/WebKit. 모든 지표의 조건과 근사 여부를 기록한다. 세션 종료 시 커밋, PROGRESS, CONTINUE, VALIDATION, PERFORMANCE 및 실제 후보 상태를 갱신한다. 강제 푸시/히스토리 재작성 금지.
