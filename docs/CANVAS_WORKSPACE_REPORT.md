## 구조

`lab/LabWorkspace`가 2D/구조형 실험실의 공통 툴바·독립 좌우 패널·집중 모드·가이드를 제공한다. 실제 `useExperiment`와 점/원본 데이터 이력은 기존 App/StructuredLab 소유권을 유지한다. 레이아웃 상태는 계산 입력 의존성에 포함하지 않는다. 캔버스 컴포넌트는 패널 토글 때 재마운트하지 않는다.

`AlgorithmPicker`는 한국어/영어/별칭/계열 검색·현재 선택·방향키·Enter·Escape를 지원한다. 탐색은 펼침/아이콘/숨김 상태와 저장 폭을 제공한다. `ResizeHandle`은 포인터 캡처, 프레임 단위 갱신, 방향키/Shift/Home/End, 더블클릭 기본값 복원을 제공한다. 데이터/설정 패널 폭도 각각 저장한다.

데이터 편집은 기존 추천·생성·프리셋·입출력·Undo/Redo·원본 표/제약 편집기를 재사용한다. 집중 모드는 이전 패널 상태를 바꾸지 않고 숨기며 종료하면 폭과 구성을 복원한다. 가이드는 필요할 때 독립 스크롤 대화상자로 연다. 도감 카드는 실행 가능한 항목만 더블클릭으로 진입하며 내부 버튼은 독립 동작한다.

`workspace.css`는 실험실에만 뷰포트 레이아웃을 적용한다. 뷰포트1200px/800px 및 작업 공간 가용 폭1100px/900px 조건에 따라 패널을 드로어로 전환하며 실제 재생 도크 높이를 관찰해 재생 버튼을 가리지 않는다. 모바일 첫 진입은 보조 패널을 닫는다. 캔버스 ResizeObserver는 실제 CSS 크기를 전달하고 requestAnimationFrame에서 DPR backing store를 갱신한다. 휠 줌은 커서 위치를 보존한다. 데이터 좌표의 종횡비는 기존 등방 투영을 유지한다.
