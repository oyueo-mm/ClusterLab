# ClusterLab 통합 개발 계획

2026-10-31. 전체 마스터 목표는 **진행 중**이다. 기존 v0.1~v0.6과 Git 기록을 보존한다. [정확한 재개 지시문](requests/2026-10-31-CONTINUATION.md)과 [직전 기반 세션 문서](sessions/foundation/)를 저장했다.

## 집계와 완료 기준

기존 13개에 신규 후보 119개를 조사·구현한다. 실제 계산, 연산 Trace, 전용 시각화, 파라미터, 수학 가이드, 독립 검증을 함께 개발한다. 별칭·초기화·구현 최적화를 독립 엔진으로 중복 계산하지 않는다. SOM/LVQ/Neural Gas/Growing Neural Gas는 관련 학습법이라는 분류를 유지한다.

현재 실행 엔진 **25개** = 기존 13 + 이전 세션 FCM/Bisecting 2 + 이번 10. 후보는 12개 실행 가능, **107개 미구현**이다. 119개 전수 원문 조사와 전체 마스터 검수는 끝나지 않았다. 엄격한 전체 기준의 완전 구현 인증은 아직 부여하지 않는다.

## 완료 단위

1. 기존 구조·테스트·32개 프리셋 해시·홈 11라운드·배포 조사 및 회귀 검사.
2. 600개 고정 제한 제거, 바이트 자원 검사, 전체 계산과 표시 LOD 분리, 실제 Worker 취소, delta 편집 이력.
3. 동적 레지스트리, 스키마 기반 파라미터, 도감과 이전 15개 엔진 통합.
4. 원본과 표시 좌표를 분리하는 Dataset union/런타임 검증. ND 수치형과 가중 무방향 그래프의 실제 실행 경로.
5. Spectral/AP/Density Peaks/CURE/Neural Gas/Growing Neural Gas/K-Medians/Mini-Batch/CLARA/CLARANS의 계산→Trace→UI→가이드→독립 수치→브라우저 통합.
6. 분석 필드 delta·행렬 공유, 실제 그래프/라플라시안/임베딩/메시지/밀도/대표점/뉴런/배치/medoid 분석.

## 다음 순서와 의존성

1. 현재 회귀·배포 증거를 확정하고 안정 체크포인트를 남긴다.
2. 107개 후보 원문·공식 구현 조사. 우선 X-Means/G-Means 및 Louvain/Leiden/Label Propagation. Leiden을 Louvain 이름 변경으로 대체하지 않는다.
3. GraphDataset에 커뮤니티 결과·모듈성·연결성·중첩, 실제 이동/정제 Trace와 독립 NetworkX/저자 구현 비교를 연결한다.
4. K-Modes/K-Prototypes·제약 알고리즘을 원본 범주/혼합/관계 데이터와 실제 편집·실행까지 통합한다.
5. CLIQUE/PROCLUS 등 부분공간, 혼합모델, 스트림/행렬/시계열을 전용 출력·시각화와 함께 구현한다.
6. 딥 군집화는 실제 학습 런타임의 용량·라이선스·호환성을 측정한다. 고정 결과 재생으로 대신하지 않는다.
7. 전송 버퍼·청크 파서·증분 실행·Worker pool·장시간 peak 측정을 진행하고 WASM/GPU는 실측 병목에 따라 도입한다.
8. 각 단위에서 전체 회귀·독립 수치·프로덕션 Worker 검증 후 기존 Pages workflow로 배포한다.

각 알고리즘을 가능한 한 실제 사용 가능한 세로 단위로 완성한다. 공통 계약 변경 전 기존 동작과 시간 탐색/되감기의 동등성을 검증한다. 데이터 스키마만 정의한 기능을 실행 지원으로 표시하지 않는다.

## 검증

작은 손계산·잘못된 입력·동일점·시드·목적함수·최종 결과·모든 Trace 전진/역진/checkpoint를 검증한다. 독립 Python NumPy/scikit-learn을 실제 실행하고 레이블 순열·중복 고유값의 기저 비유일성을 고려한다. Chromium/mobile 전체 회귀와 신규 플랫폼 Firefox/WebKit을 구분한다. 1920/1440/1024/800/768/390/320px을 검사한다.

100~100만 개를 알고리즘 특성에 맞게 측정한다. Node 시간·heap 차이는 브라우저 FPS나 peak 메모리가 아니다. 실패/자원 거부도 기록한다. PROGRESS/ALGORITHM_REGISTRY/VALIDATION/PERFORMANCE와 안정 커밋·CONTINUE를 유지하고 사용자에게 마스터 명세를 다시 요구하지 않는다.
