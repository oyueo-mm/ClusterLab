# PCKMeans — 구현 계약과 독립 검증

2026-11-03. SDM2004 Basu/Banerjee/Mooney의 [원저자 PDF](https://www.cs.utexas.edu/~ml/papers/semi-sdm-04.pdf) §2–3 및 p3 Figure1을 직접 렌더링해 확인했다. 기존 CONSTRAINT_QUEUE의 미확인 초기화 그림을 보완했다. 능동 질의·구면 거리·모순 감독·관계별 가중치는 구현 범위에 넣지 않는다. 공식 RISC 실행 코드는 확보·실행하지 못했으며 독립 NumPy 검산을 사용한다. 외부 구현 코드를 제품으로 복사하지 않는다.

## 수학과 입력

`ConstrainedDataset/v1`의 전체 ND 수치, 일관된 무가중 ML/CL과 전역 유한 비음수 비용 w를 사용한다. 기존 COP 입력 검증은 유지한다. 원문은 ½SSE+w_p·위반수, 제품은 요청한 SSE+w·위반수이므로 **w=2w_p일 때 같은 문제**다. 값 자체가 같은 비용이라고 주장하지 않는다.

ML 전이 폐쇄 및 성분 사이 CL 전파를 목적식에 실제 포함한다. CL 자체는 전이시키지 않는다. 무방향 중복은 한 관계로 취급하고 자명한 self-ML은 비용0이다. 원래 관계·유도 관계는 구분하며 어느 폐쇄 쌍도 두 번 세지 않는다. n² 쌍을 만들지 않고 성분별 군집 histogram으로 정확한 위반 수를 계산한다. ML 내부 CL은 지원하지 않는 입력 오류이고, 유효한 제약의 유한 비용 위반은 정상 결과다.

## 실행 정책

ML 다중행 성분을 크기 내림차순·최소 원본 인덱스 동률순으로 선택해 평균을 초기 중심으로 쓴다. 부족하면 모든 ML 이웃집합과 CL로 연결된 첫 비소속 행을 한 번 추가한다. 이후 전체 원본 평균에 시드 균등 잡음 ±5% 범위폭을 주어 채운다. 상수 축은 변형하지 않는다. 원문이 고정하지 않은 잡음 크기·동률 규약을 공개한다. ML 없는 경우도 이 전역 평균 perturbation 정책이다.

전체 행에 초기 최근접 label을 구성한 뒤 매 sweep 시드 Fisher–Yates 순서로 각 후보의 거리+incident ML/CL 비용을 계산한다. 다른 행의 가장 최근 label을 즉시 사용한다. 현재 label에서 엄격히 비용이 줄 때만 이동해 동률 순환을 막는다. 동률이면 현재 label을 유지하고 나머지 후보 동률은 낮은 index가 우선이다. 초기 label 완성, 빈 중심 유지, 시드 규약, 유한 반복 한도는 명시적 실행 정책이며 원문이 이들을 모두 지정했다고 하지 않는다.

군집 평균은 전체 원본 차원으로 갱신하고 빈 군집은 이전 중심을 유지한다. 실제 전체 목적을 매 sweep 재계산한다. label 안정, 목적 변화 허용오차, 반복 한도를 구분한다. 탐욕적 국소 결과이며 전역 최적·hard 만족을 보장하지 않는다. 양의 실거리 제곱의 underflow/overflow, 유한 합·중심 실패는 수치 오류로 처리한다. 임의 epsilon으로 수식을 바꾸지 않는다.

## 검증 진행

제품 엔진 작성 전에 `scripts/pckmeans_reference.py`로 Floyd closure와 모든 후보의 전체 목적 직접 재계산을 사용하는 NumPy oracle를 작성한다. 작은 K^n 전수 배정은 목적식 검산용이며 탐욕 결과의 전역 일치를 요구하지 않는다. 실행·Trace·UI·브라우저·성능 결과는 개발 단계마다 아래에 추가한다. 현재 이 문서 작성만으로 엔진 완료·원문 완전 인증 수를 올리지 않는다.
