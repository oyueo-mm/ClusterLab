﻿# 후속 PCM/FPCM 수식 확인과 독립 블록 검산

2026-11-01. **후속 연구 자료이며 제품 엔진 구현/검증 완료가 아니다.** 현재53개/후보40·79미구현/완전 인증0 집계를 바꾸지 않는다. R oracle·1993/1997 원문 전체 확인·브라우저 mini는 미실시다.

## 확인한 출처와 행렬 방향

[Pal et al.(2005) 저자 논문](https://www.comp.ita.br/~forster/CC-222/material/fuzzyclust/fuzzy01492404.pdf)의 인쇄520~523쪽을 실제 렌더링해 Eq8/10/11,15~18,20~23의 첨자를 확인했다. 1993 PCM/1997 FPCM의 저자 재서술과 새로운2005 PFCM을 구분한다. 후자의 이름을 후보22의 별칭으로 집계하지 않는다.

논문은 군집×표본 행렬이다. 아래는 제품 데이터에 맞춘 **표본×군집** 표기다. 이 전치로 인해 FPCM의 U는 각 표본의 행 합1, T는 각 군집의 열 합1이다. PCM의 전형성은 이런 행/열 합1을 요구하지 않는다. 퍼지 값이나 전형성을 Bayes 사후확률로 부르지 않는다.

## 다음 구현의 수학 계약

D_ij²=||x_i−v_j||², m>1,η>1로 둔다. 양의 거리에서 FPCM의 조건부 최적 갱신은

\[
u_{ij}=\frac{(D_{ij}^2)^{-1/(m-1)}}{\sum_h(D_{ih}^2)^{-1/(m-1)}},\quad
t_{ij}=\frac{(D_{ij}^2)^{-1/(\eta-1)}}{\sum_l(D_{lj}^2)^{-1/(\eta-1)}},\quad
v_j=\frac{\sum_i(u_{ij}^m+t_{ij}^{\eta})x_i}{\sum_i(u_{ij}^m+t_{ij}^{\eta})}.
\]

목적은 Σ_ij(u^m+t^η)D²다. 거리0은 별도 최적해 집합이며, 양의 거리 항에0을 주고 영거리 동률에 합1을 분배하는 정책을 명시해야 한다. 분모에 임의 epsilon을 넣고 원래 목적의 정확 갱신이라고 하지 않는다.

고정 양수 척도 Ω_j에서1993 형태 PCM의 목적과 전형성은

\[
J=\sum_{ij}t_{ij}^{\eta}D_{ij}^2+\sum_j\Omega_j\sum_i(1-t_{ij})^{\eta},\qquad
t_{ij}=\frac1{1+(D_{ij}^2/\Omega_j)^{1/(\eta-1)}}.
\]

FCM 기반 척도 추정은 Ω_j=κ·Σu^mD²/Σu^m다. κ는 군집 수 K와 다른 차원 없는 계수다. 논문Eq11의 양수 척도와 초기화/고정 정책을 보존한다. 기존2D FCM을 ND warm-start로 사용하지 않는다. Ω=0·빈 가중치·중복 중심·수치 underflow의 정책은 아직 제품에 구현하지 않았다.

PFCM2005는 거리항 aU^m+bT^η와 별도 penalty를 가진다. 같은 Ω에서 T의 갱신에는 bD²/Ω가 들어간다. a,b는 혼합확률이 아니며 a+b=1을 강제하면 다른 모형을 만들 수 있다. 현재는 관련 방법의 구분 자료다.

## 실제 독립 NumPy 검산

NumPy2.5.4로 고정 데이터 X=[0,1,4], 중심 V=[0.5,3], m=η=2를 사용했다. 모든 거리가 양수인 블록 한 단계의 검산이며 전체 군집화 실행이나 제품 비교가 아니다.

D²=[[0.25,9],[0.25,4],[12.25,1]]이다. U의 세 행은 [36/37,1/37], [16/17,1/17], [4/53,49/53]이고 T의 두 열은 [49/99,49/99,1/99], [4/49,9/49,36/49]다. 행/열 합, 고정 중심의 KKT 미분값을 직접 확인했다.

| 검사                        | 실제 값/결과                                     |
| --------------------------- | ------------------------------------------------ |
| 균등 U/T의 FPCM 목적        | 9.659722222222221                                |
| U/T 조건부 갱신 후          | 2.2614969140654884                               |
| 가중 중심 갱신 후           | 1.0908190674992306                               |
| 새 중심                     | 0.49564537479322524,3.901908087734169            |
| 각 표본을3번 복제한 새 중심 | 0.4944754135176862,3.970208691185815             |
| PCM D²=4,Ω=1,η=2            | T=0.2,J=0.8. [0,1]의10001개 격자에서도 같은 최소 |

복제 효과는 자체 수학 검산이다. r번 복제하면 U는 그대로 반복되고 T는1/r로 줄어든다. U^m 항의 합은r배, T^η 항은r^(1−η)배이므로 두 항의 상대 영향이 바뀐다. T를 보기 좋게 행 정규화한 값을 실제 계산에 덮어쓰면 이 모형을 재현하지 못한다.

PCM의 같은 데이터/중심과 Ω=[1,2]에서 T의 행 합은 약0.981818,1.133333,0.742138이었다. 합1로 강제하지 않는 실제 최적 전형성이다. 같은 a:b 비율이라도 b=1과b=0.5는 고정 Ω의 PFCM T를 다르게 만들었다.

재현할 최소 계산은 다음과 같다. 실제 수행한 추가 검사는 위 KKT·목적 비증가·복제 스케일·PCM 미분·스칼라 격자다.

```python
import numpy as np
x = np.array([[0.], [1.], [4.]])
v = np.array([[.5], [3.]])
d2 = ((x[:, None, :] - v[None, :, :]) ** 2).sum(axis=2)
z = 1 / d2
u = z / z.sum(axis=1, keepdims=True)
t = z / z.sum(axis=0, keepdims=True)
w = u**2 + t**2
v_next = w.T @ x / w.sum(axis=0)[:, None]
np.testing.assert_allclose(u.sum(axis=1), 1)
np.testing.assert_allclose(t.sum(axis=0), 1)
print(u, t, v_next)
```
